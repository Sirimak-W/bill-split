# หารค่าข้าว — v1.0.0

เว็บแอปหารค่าอาหารกับเพื่อน เลือกได้ว่าใครกินรายการไหน แล้วระบบคิด Service charge และ VAT ให้ตามสัดส่วน

## ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---|---|
| สมาชิก | เพิ่ม แก้ หรือลบชื่อได้ ชื่อในทุกรายการเปลี่ยนตามอัตโนมัติ |
| สแกนบิลด้วย AI | ถ่ายรูปหรือเลือกรูปใบเสร็จ แล้วได้รายการ ราคา Service % VAT % และยอด Total อัตโนมัติ |
| เลือกคนที่กิน | ปุ่มชื่อในแต่ละรายการ กด "ทุกคน" เพื่อเลือกหรือยกเลิกทั้งหมด รายการที่ยังไม่มีใครถูกเลือกจะขึ้นเตือน |
| ออกให้เพื่อน | ตั้งได้ทีละรายการ ทีละคน เช่น แนทออกส่วนเบียร์ของปั่น ส่วนนั้นจะย้ายไปอยู่ในยอดของแนท |
| ราคารวม Service / VAT แล้ว | เลือกได้ 4 แบบ: ยังไม่รวม / รวม Service แล้ว / รวม VAT แล้ว / รวมทั้งคู่แล้ว |
| ปัดเศษ | ปัดเป็นบาทเต็มแบบ largest remainder ยอดรวมยังตรงกับบิล |
| เทียบยอดบิล | เทียบยอดที่คำนวณได้กับยอด Total ในบิล ถ้าตรงขึ้น ✓ ถ้าไม่ตรงขึ้นเตือน |
| โอนเงิน | ใส่พร้อมเพย์ (เบอร์มือถือหรือเลขบัตรประชาชน) หรือเลขบัญชีธนาคาร |
| QR พร้อมเพย์รายคน | แต่ละคนได้ QR ที่ใส่ยอดของตัวเองไว้แล้ว ตามมาตรฐาน Thai QR / EMVCo |
| คัดลอกสรุป | ได้ข้อความสรุปยอดรายคน รายการที่ออกให้กัน และช่องทางโอน ไว้แปะในแชท |
| โหมดมืด/สว่าง | ปุ่มมุมขวาบน จำค่าไว้ในเบราว์เซอร์ |
| ไม่เก็บข้อมูล | ไม่บันทึกข้อมูลบิล เปิดหน้าใหม่หรือกด "เริ่มบิลใหม่" (กด 2 ครั้ง) แล้วเริ่มจากว่าง |

## วิธีใช้

1. พิมพ์ชื่อสมาชิกให้ครบทุกคน
2. กด **ถ่าย / เลือกรูปบิล** แล้วรอ AI อ่านบิลประมาณ 10–40 วินาที
3. ทุกรายการตั้งเป็น "ทุกคน" ไว้ก่อน ให้กดชื่อคนที่ไม่ได้กินออก
4. ถ้ามีคนออกให้เพื่อน กด **ออกให้เพื่อน…** ใต้รายการนั้น แล้วเลือกว่าใครออกส่วนของใคร
5. ตรวจปุ่ม "ราคาในบิลนี้" และค่า Service / VAT ให้ตรงกับบิล
6. ใส่พร้อมเพย์หรือเลขบัญชีในช่อง **โอนเงินให้**
7. กด **คัดลอกสรุปไปส่งในแชท** หรือเปิด QR ของแต่ละคนให้สแกนจ่าย

## วิธีคำนวณ

```
ส่วนของแต่ละคนต่อรายการ = ราคารายการ ÷ จำนวนคนที่กิน
ยอดก่อนค่าบริการ        = ผลรวมส่วนของตัวเอง (รวมส่วนที่ออกให้เพื่อน)
ตัวคูณ                  = (1 + Service%) × (1 + VAT%)   ← ส่วนที่รวมในราคาแล้วนับเป็น 1
ยอดที่ต้องจ่าย           = ยอดก่อนค่าบริการ × ตัวคูณ → ปัดเศษแบบ largest remainder
```

## ข้อจำกัดที่รู้แล้ว

- QR พร้อมเพย์ผ่านการตรวจ payload และ CRC แล้ว แต่ยังไม่ได้ทดสอบกับแอปธนาคารจริง ควรลองสแกนเองก่อนใช้
- การสแกนบิลต้องล็อกอิน Claude และใช้โควต้าของบัญชีคนที่สแกน
- ถ้าเลือก "รวม VAT แล้ว" ระบบคิด Service จากราคาที่รวม VAT แล้ว บางร้านคิด Service จากราคาก่อน VAT ยอดจึงอาจต่างกันไม่กี่บาท
- รองรับบัญชีพร้อมเพย์แบบเบอร์มือถือ 10 หลัก เลขบัตรประชาชน 13 หลัก และ e-Wallet 15 หลัก
